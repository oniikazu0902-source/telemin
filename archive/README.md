# archive/ — 開発初期の試作ファイル

`telemin.py` ができるまでの試作版を、記録として残しているフォルダです。
**現在のプログラムからは使われていません。** 実行するときは `telemin.py`（`start_telemin.bat`）を使ってください。

これらのファイルはどれも `hand_landmarker.task` を「実行したときのフォルダ」から読み込みます。動かしたい場合は、リポジトリのルート（`hand_landmarker.task` がある場所）で `python archive/2hands.py` のように実行してください。

| ファイル | 最終更新 | 内容 |
|---|---|---|
| `main.py` | 2026-07-08（Initial commit） | 最初期の試作。片手（`num_hands=1`）の人差し指の高さで音程（半音階）、手の開き具合（手首〜中指先の距離）で音量（CC#7）を送る。音階の制限なし |
| `1hand.py` | 2026-06-03 | 音階制限（`CHORD_MODE` / `ALLOWED_NOTES`）を追加。名前は 1hand だが検出は2本の手まで |
| `2hands.py` | 2026-06-10 | 両手対応。スケール切替（`KEY_PRESETS`）、上下の有効エリア（`Y_MIN_LIMIT` / `Y_MAX_LIMIT`）、ピンチ（親指と人差し指）による音量を追加 |
| `0617.py` | 2026-06-17 | 波形を変える CC#16 の送信と、画面への音程ガイド線・文字表示を追加（元のファイル名は拡張子なしの `0617`） |
| `0624.py` | 2026-06-24 | `WAVE_MODE`（CC#16 の ON/OFF 切替）を追加。`telemin.py` の直接の元になった版 |
| `hoge.py` | 2026-07-08 | `0624.py` とほぼ同じ内容（末尾の改行の有無だけが違う）。Initial commit 時のコピー |

各ファイルの変更の経緯は `git log --follow archive/<ファイル名>` で、移動前の履歴まで含めて確認できます。
